- **Biggest corrections:**
  - **The "0% independent" figure is partly built into the method.** The classifier has no rule that can ever mark a payer "independent". Any wallet that isn't the fee distributor, creator or authority falls into "unattributed". So 0% is a ceiling claim ("≤5% could be outside money"), not a measurement. The card has to say "not shown to be outside revenue", never "0% outside".
  - **The 123.75 SOL sample is really 2 agents.** KNIGHT's team wallet (53.99 SOL) and Solana AI (34.92 SOL) make up 72%. RKC, the agent that took 64% of all buyback spend, contributes only its 0.78 SOL unattributed transfer, because its fee inflows were never summed. Deposit windows run from March to October, while the US$3.1k buyback figure covers a ~37-day window. Not blind, one bot, no hand labels.
  - **The free test plan has idea bot labelling** ("Label (idea bot, claimed in claims.md)"). Our blind rules say idea bot never labels or judges. Trench Bot labels, Git bot second-labels, Project Bot judges.

## Fact-check (opened 11:11-11:15am AWST)
- **CFO doesn't attribute funders:** correct (quoted above).
- **Dewash 1 sale:** correct. x402gle shows "all-time $4.99 / 1 settlements", 0 in the last 24h.
- **233,878 Tokenized Agent accounts / 73 with buybacks / ~US$3.1k in ~37 days:** consistent with idea bot's own files. `agents.json` has 233,878 entries and `buyback_spend.json` has 73. 30.03 SOL × US$102.51 + 10.75 USDC ≈ US$3,089. I didn't re-run the on-chain pull. The 73 comes from the crank's latest 1,200 transactions, so it's a ~37-day window, not a 30-day one.
- **pump.fun competition terms ban wash trades:** correct, and stronger than stated. The [terms](https://pump.fun/docs/app-competition-terms) (last updated 23 Oct 2026) define a Wash Trade as including "trades executed between wallets controlled by the same person or coordinated persons (including between the wallets of members of the same Squad)". s 4A.6 makes trades between squad members Manipulative Trading. The "ends 9 Nov" date sits on the in-app Competition Page, which I didn't verify.
- **Split arithmetic (RESULT.md):** adds up. Recycled 8.63 + 2.68 + 29.20 + 14.13 + 8.62 = 63.26 SOL (51.1%); team 53.99 (43.6%); unattributed 5.72 + 0.78 = 6.50 (5.3%); total 123.75. Caveats are listed in the Verdict.
- **Wording risk:** "recycled creator fees" is the coin's own traders' fees, routed in by a disclosed pump.fun setting. That's real money from traders, just not product revenue. The label must say "funded by this coin's trading fees", not imply fraud.

## Build plan (recommended path: Receipts as a parked Clean Feed Pro add-on)
**Gate 0 (no Receipts work before this):** Clean Feed's copy engine passes Mint Seal Part B on the locked pass line. If it fails, Receipts stays parked.
1. **Free private test (A$0, nothing public). Roles:** Trench Bot labels, Git bot second-labels blind, Project Bot judges. Idea bot neither labels nor judges.
   - Before labelling, freeze a rule that can mark a payer "outside customer". For example: at least 3 distinct payers, none sharing a funder within 2 hops with the creator, authority or each other, wallet older than 30 days, not a CEX hot wallet. Without it, 0% is guaranteed.
   - Trench Bot hand-labels the payer class (outside customer, recycled creator fees, team wallet, unattributed) on 40 receipts: the 8 agents plus 32 self-posted buyback coins from X bot's data, excluding $CLAWD and the 7 test agents from scoring, since they've been seen.
   - Git bot blind-labels 30 of them. Labels go in a sealed folder.
   - Hash the frozen classifier's predictions before any label is opened.
   - **Pass:** 85%+ label agreement between the two bots (kappa 0.7+), the classifier matches the agreed labels on 85%+, and the false "team wallet" rate is under 5%.
2. **Head-to-head (Git bot):** on the same 40 coins, record what CFO's check, SolEnrich and pumpdata.fun return.
3. **Count check (X bot, read-only):** a 7-day count of distinct pump.fun coins that self-post buyback or revenue receipts.
4. **If all pass:** a 2-week build on Clean Feed's VPS. Week 1: indexer for agent deposits, fee-sharing distributions and 2-hop funders, plus CEX list.
